## Hi, ich bin Nico.

Ich studiere Angewandte Informatik an der HTWG Konstanz. Besonders interessieren mich die Bereiche, in denen Softwareentwicklung, Rechnernetze und IT-Sicherheit aufeinandertreffen.

Im Studium und in eigenen Projekten habe ich schnell gemerkt, dass funktionierender Code allein noch kein gutes System ergibt. Sobald verschiedene Komponenten miteinander kommunizieren, Daten verarbeitet oder Schnittstellen nach außen geöffnet werden, entstehen neue Fehlerquellen und Sicherheitsrisiken.

Aus diesem Grund habe ich mich für ein Praxissemester im Penetration Testing entschieden. Dort konnte ich Anwendungen aus einer anderen Perspektive betrachten: nicht nur mit der Frage, wie sie entwickelt wurden, sondern auch, auf welchen Annahmen sie basieren, wie sie sich unter unerwarteten Bedingungen verhalten und an welchen Stellen diese Annahmen brechen können.

Diese Verbindung aus Entwicklung und Security prägt inzwischen meine Arbeitsweise. Ich möchte nicht nur wissen, **ob** eine Lösung funktioniert, sondern auch verstehen, **warum** sie funktioniert, wo ihre Grenzen liegen und wie sie sich möglichst robust umsetzen lässt.

## Wenn KI den Code schreibt - was bleibt die Aufgabe des Informatikers?

Gerade durch KI wird das Verständnis hinter dem Code für mich noch wichtiger. KI kann innerhalb weniger Sekunden Implementierungen erzeugen, nimmt einem aber weder die technischen Entscheidungen noch die Verantwortung für das Ergebnis ab.

Jemand muss weiterhin das eigentliche Problem verstehen, Anforderungen sinnvoll übersetzen und entscheiden, wie ein System aufgebaut sein soll. Ebenso muss jemand erkennen, wenn eine Lösung nur plausibel aussieht, aber falsche Annahmen enthält, Sicherheitsrisiken erzeugt oder unter realen Bedingungen nicht zuverlässig funktioniert.

Genau dort sehe ich meinen Schwerpunkt: Zusammenhänge verstehen, größere Probleme in überschaubare Komponenten zerlegen und anschließend beurteilen, ob daraus wirklich eine tragfähige Lösung entstanden ist. KI ist für mich deshalb keine Alternative zu technischem Verständnis, sondern ein Werkzeug, mit dem sich dieses Verständnis schneller in funktionierende Software übersetzen lässt.

> **Weniger akademisch ausgedrückt:** KI ist die Pille der Softwareentwicklung. Entwickler sind das Kondom zwischen generiertem Code und Production - denn doppelte Absicherung ist immer noch günstiger als die Folgen.
