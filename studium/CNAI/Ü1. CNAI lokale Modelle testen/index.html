    Teil 1 - Setup und erster Modellaufruf¶

    F1: Lest compose.yaml, app/llm.py und app/hallo_llm.py. Beschreibt im README in drei, vier Sätzen: Welche Container laufen, und wie findet die Anwendung das Modell?

    Docker compose startet 3 Container: Ollama - Stellt die Api bereit, modell-laden - abhängig von Ollama und lädt beide Modelle herunter, app - führt das Pythonscript aus.

    Die Anwendung findet das Modell über .env. Die Base URL API über http://ollama:11434/v1  und LLM Model bestimmt welches Modell verwendet wird für die Fragen die über das Script gestellt werden.

    Teil 3 - Samplings und Tokens messen¶

    Sampling:¶

    Das Skript Sampling stellt dieselbe Frage je fünfmal bei Temperature 0, 0,7 und 1,2 und zählt die verschiedenen Antworten.

    F1: Wie viele verschiedene Antworten bekommt man bei jeder Temperatur?

    A1

    Temperature Gerichtnamen – Lauf 1 Gerichtnamen – Lauf 2 Faktenfrage
    0,0 1 1 1
    0,7 4 4 3
    1,2 5 5 5

    F2: Liefert Temperature 0 wirklich fünfmal dieselbe Antwort? Wenn nicht: Woran könnte das liegen?
    A2: In diesem Test ja, aber sehr abhängig von Hardware, sogar parallele Prozesse oder caching sowie seed von zufallsgenerator beeinflussen das Ergebnis. Ein einfacher Großbuchstabe könnte schon starke Abweichungen erzielen.

    Sampling Skript mit Faktenfrage starten "Ist die HTWG Konstanz eine private oder staatliche Hochschule? Antworte mit einem Satz."
    F3: Welche Fehler kommen schon bei Temperature 0 vor, welche erst bei höheren Werten? Was sagt das über die Ursache (Sampling oder Trainingsdaten)?

    A3:

    Temperature Beobachtete Fehler
    0,0 Immer „Hochschule für Technik und Wirtschaft“: „Gestaltung“ fehlt.
    0,7 Falscher Name: „Hochschule für Technologie, Wirtschaft und Geisteswissenschaften“. „Staatlich anerkannt“ beantwortet zudem nicht eindeutig, ob die Hochschule staatlich oder privat ist.
    1,2 Weitere falsche Namen, etwa „Hochschule für Technomatisierung der Wahl Grettenberg“.

    Der Fehler bei Temperature 0 deutet auf unzuverlässiges Modellwissen hin. Höhere Temperaturen begünstigen zusätzlich ungewöhnliche und falsche Fortsetzungen. Bei Temperature 0 lässt er fehlendes Wissen einfach aus in diesem Fall der "Gestaltung" Teil.

    Tokens:¶

    Das Skript misst, wie viele Eingabe-Tokens die deutsche und die englische Frage brauchen, und vergleicht die Zahlen. Die eigentliche Antwort interessiert hier nicht.
